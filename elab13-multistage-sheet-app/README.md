# ใบงานการทดลองที่ 13: วงจรขยายสัญญาณหลายภาค (Multi-Stage BJT Amplifier)

แอปพลิเคชันห้องปฏิบัติการเสมือนจริงแบบ Interactive สำหรับการวิเคราะห์วงจรขยาย Common-Emitter 2 ภาค แบบ RC-Coupled Cascade พร้อมระบบตรวจข้อสอบและตัดเกรดอัตโนมัติเชื่อมโยง Google Sheets

## โครงสร้างไฟล์
- `index.html`: หน้าเว็บแอปพลิเคชัน 4-Tab (ทฤษฎี, ห้องทดลองจำลองเสมือน, ตารางบันทึกผล, คำถามและสรุปผล)
- `Code.js`: ฝั่ง Backend บน Google Apps Script (คำนวณและตรวจคะแนนอัตโนมัติ 10 คะแนน พร้อมบันทึกผลลง Google Sheets)
- `appsscript.json`: การตั้งค่า Manifest ของ Google Apps Script

## ขั้นตอนการติดตั้งและ Deploy บน Google Apps Script
1. สร้าง **Google Sheets** เปล่าใหม่ขึ้นมา 1 ไฟล์
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. คัดลอกโค้ดจากไฟล์ `Code.js` ไปวางในโปรเจกต์ Apps Script
4. สร้างไฟล์ HTML ตั้งชื่อว่า `index` แล้วคัดลอกโค้ดจากไฟล์ `index.html` ไปวาง
5. กด **บันทึก (Save)**
6. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New Deployment)**
7. เลือกประเภทเป็น **เว็บแอป (Web App)**
8. ตั้งค่า:
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
9. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก Web App URL เพื่อส่งให้นักศึกษาเข้าทำปฏิบัติการ

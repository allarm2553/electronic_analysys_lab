ใบงานการทดลองที่ 15: วงจรกรองความถี่ต่ำและความถี่สูงแบบพาสซีฟ

Passive RC Low-Pass & High-Pass Filters (Frequency Response & Bode Plot)
กลับสู่ E-Lab Portal

วัตถุประสงค์การทดลอง (Objectives)

  • เพื่อศึกษาหลักการทำงานและการตอบสนองต่อความถี่ของวงจรกรองความถี่ต่ำ (RC Low-Pass Filter) และความถี่สูง (RC High-Pass Filter) แบบพาสซีฟ
  • เพื่อคำนวณและทดสอบหาความถี่คัทออฟ (Cutoff Frequency, \(f_c\)) หรือจุดตัด \(-3\text{ dB}\) จากสูตร \(f_c = \frac{1}{2\pi RC}\)
  • เพื่อวิเคราะห์อัตราขยายแรงดันในหน่วยอัตราส่วนสัมบูรณ์ (\(A_v = V_{out}/V_{in}\)) และหน่วยเดซิเบล (\(A_v(\text{dB}) = 20\log_{10}(A_v)\))
  • เพื่อสังเกตการเลื่อนเฟส (Phase Shift, \(\theta\)) ระหว่างสัญญาณแรงดันอินพุตและเอาต์พุตบนออสซิลโลสโคปคู่
  • เพื่อศึกษาการเปลี่ยนแปลงจุดตัด \(f_c\) เมื่อปรับเปลี่ยนค่าความต้านทาน \(R\) และตัวเก็บประจุ \(C\)

1. วงจรกรองความถี่ต่ำ (RC Low-Pass Filter: LPF)

วงจร LPF ประกอบด้วยตัวต้านทาน \(R\) ต่ออนุกรม และตัวเก็บประจุ \(C\) ต่อขนานกับสัญญาณเอาต์พุต ที่ความถี่ต่ำ \(X_C = \frac{1}{2\pi f C}\) จะมีค่าสูงมาก แรงดันส่วนใหญ่จึงตกคร่อมที่ \(C\) (\(V_{out} \approx V_{in}\)) ขณะที่ความถี่สูง \(X_C\) จะลดลงจนชอร์ตสัญญาณลงกราวด์

ความถี่คัทออฟ (Cutoff Frequency):
\[f_c = \frac{1}{2\pi R C}\]
อัตราขยายแรงดัน (Voltage Gain):
\[|A_v| = \frac{V_{out}}{V_{in}} = \frac{1}{\sqrt{1 + (f / f_c)^2}}\]
อัตราขยายในหน่วยเดซิเบล (dB):
\[A_v(\text{dB}) = 20 \log_{10}(|A_v|)\]
มุมต่างเฟส (Phase Shift):
\[\theta = -\arctan\left(\frac{f}{f_c}\right) \quad (\text{ที่ } f=f_c \implies \theta = -45^\circ)\]

💡 แบนด์วิดท์ (Bandwidth): สำหรับ LPF แบนด์วิดท์มีค่าเท่ากับ \(BW = f_c\) (ช่วง \(0\text{ Hz}\) ถึง \(f_c\))

2. วงจรกรองความถี่สูง (RC High-Pass Filter: HPF)

วงจร HPF ประกอบด้วยตัวเก็บประจุ \(C\) ต่ออนุกรมทางอินพุต และตัวต้านทาน \(R\) ตกคร่อมเอาต์พุตลงกราวด์ ที่ความถี่ต่ำ \(C\) ทำหน้าที่เป็นตัวกั้นไฟ DC/ความถี่ต่ำ (\(X_C\) สูงมาก) จึงไม่มีสัญญาณออก แต่ที่ความถี่สูง \(X_C\) จะต่ำมาก สัญญาณจึงผ่านไปยัง \(R\) ได้เกือบทั้งหมด

ความถี่คัทออฟ (Cutoff Frequency):
\[f_c = \frac{1}{2\pi R C}\]
อัตราขยายแรงดัน (Voltage Gain):
\[|A_v| = \frac{V_{out}}{V_{in}} = \frac{(f / f_c)}{\sqrt{1 + (f / f_c)^2}} = \frac{1}{\sqrt{1 + (f_c / f)^2}}\]
อัตราขยายในหน่วยเดซิเบล (dB):
\[A_v(\text{dB}) = 20 \log_{10}(|A_v|)\]
มุมต่างเฟส (Phase Shift):
\[\theta = +\arctan\left(\frac{f_c}{f}\right) \quad (\text{ที่ } f=f_c \implies \theta = +45^\circ)\]

💡 มุมเฟส HPF: เอาต์พุตจะนำหน้าอินพุต \(+45^\circ\) ที่จุดคัทออฟ และนำหน้า \(+90^\circ\) ที่ความถี่ต่ำมาก

3. ทฤษฎีเดซิเบล (Decibel) และความหมายของจุดตัด -3 dB

ในทางวิศวกรรมอิเล็กทรอนิกส์ การใช้อัตราส่วนแบบลอการิทึม (Logarithmic Scale) ในหน่วย **เดซิเบล (Decibel: dB)** ช่วยให้สามารถวิเคราะห์สัญญาณที่มีช่วงความถี่กว้างขวางหลายทศวรรษ (Decades) ได้อย่างสะดวก:

  • ที่ย่านส่งผ่าน (Passband): \(A_v = 1.00 \implies A_v(\text{dB}) = 20\log_{10}(1) = \mathbf{0\text{ dB}}\) (สัญญาณผ่านได้ 100%)
  • ที่จุดความถี่คัทออฟ (\(f = f_c\)): \(A_v = \frac{1}{\sqrt{2}} \approx 0.7071 \implies A_v(\text{dB}) = 20\log_{10}(0.7071) = \mathbf{-3.01\text{ dB} \approx -3\text{ dB}}\)
  • กำลังไฟฟ้าครึ่งหนึ่ง (Half-Power Point): เนื่องจากกำลังไฟฟ้าแปรผันตามแรงดันยกกำลังสอง (\(P \propto V^2\)) ดังนั้นที่จุด \(-3\text{ dB}\) กำลังไฟฟ้าที่โหลดได้รับจะลดลงเหลือ **\(50\%\)** หรือครึ่งหนึ่งของค่าสูงสุด
  • อัตราความชันการลดทอน (Roll-off Rate): สำหรับวงจรกรองอันดับที่ 1 (First-Order RC Filter) เมื่อความถี่พ้นจุดคัทออฟไป อัตราการลดทอนจะมีความชันคงที่เท่ากับ **\(-20\text{ dB/decade}\)** หรือ **\(-6\text{ dB/octave}\)**

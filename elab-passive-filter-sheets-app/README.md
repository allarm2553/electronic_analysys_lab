# ใบงานการทดลองที่ 15: วงจรกรองความถี่ต่ำและความถี่สูงแบบพาสซีฟ (Passive RC Filters)

ระบบจำลองปฏิบัติการวิเคราะห์วงจรกรองความถี่ต่ำ (Low-Pass Filter) และความถี่สูง (High-Pass Filter) แบบ RC พาสซีฟ รองรับการจำลองกราฟการตอบสนองความถี่ (Bode Plot), ออสซิลโลสโคป 2 แชนแนล (Dual-Trace Scope), แผนภาพวงจร SVG และระบบตรวจประเมินผลอัตโนมัติ 10 คะแนนเต็ม เชื่อมต่อ Google Sheets

## วัตถุประสงค์การทดลอง
1. เพื่อศึกษาหลักการทำงานของวงจรกรองความถี่ต่ำ (RC Low-Pass Filter) และวงจรกรองความถี่สูง (RC High-Pass Filter) แบบพาสซีฟ
2. เพื่อคำนวณและวัดค่าความถี่คัทออฟ (Cutoff Frequency, $f_c$) หรือจุดตัด $-3\text{ dB}$ ($f_c = \frac{1}{2\pi RC}$)
3. เพื่อวิเคราะห์อัตราขยายในหน่วยเดซิเบล ($A_v(\text{dB}) = 20 \log_{10}(V_{out}/V_{in})$) และแบนด์วิดท์ (Bandwidth) ของวงจร
4. เพื่อสังเกตมุมต่างเฟส (Phase Shift, $\theta$) ระหว่างสัญญาณอินพุตและเอาต์พุตบนออสซิลโลสโคปที่ความถี่ต่างๆ
5. เพื่อทดลองปรับเปลี่ยนค่าความต้านทาน ($R$) และตัวเก็บประจุ ($C$) เพื่อศึกษาผลกระทบต่อจุดคัทออฟและความชันการลดทอน (Roll-off Rate, $-20\text{ dB/decade}$)

## สถาปัตยกรรมระบบ (4-Tab Layout)
- **Tab 1 (📖 ทฤษฎีและคู่มือแล็บ):** สมการคณิตศาสตร์ KaTeX, นิยามจุดตัด $-3\text{ dB}$, แบนด์วิดท์, การคำนวณเดซิเบล และตารางเปรียบเทียบ LPF vs HPF
- **Tab 2 (🔬 ห้องทดลองจำลองเสมือน):** ตัวปรับค่า $R$, $C$, ความถี่ฟังก์ชันเจเนอเรเตอร์ พร้อม 3 มุมมอง:
  - ⚡ แผนภาพวงจรจริง (SVG Dynamic Schematic)
  - 📊 กราฟการตอบสนองความถี่ (Bode Plot - Log Scale with -3dB point)
  - 📡 ออสซิลโลสโคปคู่สด (Dual-Trace Live Scope with Phase Shift)

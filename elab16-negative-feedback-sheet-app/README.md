# ใบงานการทดลองที่ 16: วงจรขยายแบบป้อนกลับลบ (Negative Feedback Amplifiers)

ระบบจำลองปฏิบัติการวิเคราะห์วงจรขยายที่มีการป้อนกลับแบบลบ (Negative Feedback) ครอบคลุมการวิเคราะห์อัตราขยายวงปิด ($A_f$), ตัวประกอบความไม่ไวต่อการเปลี่ยนแปลง ($1 + A\beta$), การขยายแบนด์วิดท์ ($BW_f = BW \times (1 + A\beta)$), การปรับปรุงอินพุต/เอาต์พุตอิมพีแดนซ์ ($Z_{in(f)}, Z_{out(f)}$) และการลดความเพี้ยนฮาร์มอนิก ($D_f = D / (1 + A\beta)$)

## วัตถุประสงค์การทดลอง
1. เพื่อศึกษาหลักการและแนวคิดของการป้อนกลับแบบลบ (Negative Feedback Concept) ในวงจรขยายอิเล็กทรอนิกส์
2. เพื่อคำนวณและพิสูจน์สมการอัตราขยายวงปิด $A_f = \frac{A}{1 + A\beta}$ และสัดส่วนป้อนกลับ $\beta = \frac{R_1}{R_1 + R_f}$
3. เพื่อสังเกตผลของการป้อนกลับลบต่อการรักษาเสถียรภาพของอัตราขยาย (Gain Desensitivity) เมื่ออัตราขยายวงเปิด $A$ เปลี่ยนแปลง
4. เพื่อศึกษาการขยายแถบความถี่ตอบสนอง (Bandwidth Extension) และคุณสมบัติคงที่ของ Gain-Bandwidth Product (GBW)
5. เพื่อวิเคราะห์การปรับปรุงอิมพีแดนซ์และการลดทอนความเพี้ยนไม่เชิงเส้น (Harmonic Distortion Reduction) บนออสซิลโลสโคป

Lab 11: Multi-Stage CE Amp V1.0

วงจรขยายสัญญาณหลายภาค (Multi-Stage BJT Amplifier)

2-Stage Common-Emitter RC-Coupled Cascade · Av(total) = Av1 × Av2

🟢 สถานะ: ออนไลน์พร้อมจำลอง

📌 วัตถุประสงค์การทดลอง

  • เพื่อศึกษาหลักการต่อวงจรขยายสัญญาณแบบหลายภาค (Cascaded Multi-Stage Amplifier) ชนิด Common-Emitter 2 ภาค ด้วย RC-Coupling
  • เพื่อวิเคราะห์จุดทำงาน DC (Q-point) ของ ภาคที่ 1 (Stage 1) และ ภาคที่ 2 (Stage 2) แยกกัน
  • เพื่อคำนวณอัตราขยายรวม Av(total) = Av1 × Av2
  • เพื่อสังเกตการกลับเฟส 180° × 2 ทำให้สัญญาณเอาต์พุต มีเฟสเดิม (0° In-Phase)
  • เพื่อวิเคราะห์ผลกระทบของโหลด RL และตัวเก็บประจุบายพาส CE2 ต่ออัตราขยายรวม

📐 ทฤษฎี: อัตราขยายรวมแบบหลายภาค

เมื่อต่อวงจรขยายหลายภาคเรียงกัน อัตราขยายรวมเท่ากับ ผลคูณ ของอัตราขยายแต่ละภาค:

Av(total) = Av1 × Av2

ในหน่วยเดซิเบล (dB): Av(dB) = Av1(dB) + Av2(dB)

เฟสรวม = 180° + 180° = 360° ≡ 0° (In-Phase)

⚠️ สัญญาณ Vout ของวงจร 2-Stage CE มีเฟสตรงกัน (0°) กับ Vin

🔗 ตัวเก็บประจุคัปปลิ้ง (RC Coupling)

  • บล็อกไฟตรง (DC Block): ป้องกันไม่ให้แรงดัน DC Bias ของภาคที่ 1 รบกวนภาคที่ 2
  • ผ่านสัญญาณ AC: ยอมให้สัญญาณ AC ไหลผ่านได้โดยไม่มีการสูญเสีย (XC ≈ 0)
R'C1 = RC1 ‖ Zin(Stage2)
Zin(Stage2) = R5 ‖ R6 ‖ β(re2 + RE2)

💡 โหลดจากอินพุตภาค 2 ทำให้ R'C1 < RC1 ส่งผลให้ Av1 ลดลงเมื่อเทียบกับตอนไม่มีโหลด

📊 สูตรคำนวณ re Model สำหรับ 2-Stage CE

Stage 1 — CE Unbypassed (ไม่มี CE1)
Vth1 = VCC·R2 / (R1+R2)
IE1 = (Vth1 − VBE) / (Rth1/(β+1) + RE1)
re1 = 26mV / IE1(mA)
Av1 = −R'C1 / (re1 + RE1)
Zi = R1 ‖ R2 ‖ β(re1 + RE1)
Stage 2 — CE Bypassed (มี CE2)
Vth2 = VCC·R6 / (R5+R6)
IE2 = (Vth2 − VBE) / (Rth2/(β+1) + RE2)
re2 = 26mV / IE2(mA)
R'C2 = RC2 ‖ RL
Av2 = −R'C2 / re2

Lab 10: h-Parameter V1.0

การวิเคราะห์วงจรขยายสัญญาณด้วยแบบจำลอง h-Parameter ของ BJT

BJT AC Small-Signal Analysis using Hybrid (h-Parameter) Two-Port Model

🟣 สถานะ: ออนไลน์พร้อมจำลอง

📌 วัตถุประสงค์การทดลอง

  • เพื่อศึกษาและทำความเข้าใจโครงสร้าง แบบจำลองไฮบริดพารามิเตอร์ (Hybrid h-Parameter Model) ของทรานซิสเตอร์ BJT โครงสร้าง Common-Emitter (CE)
  • เพื่อสกัดหาค่าพารามิเตอร์ hie (ความต้านทานอินพุต) และ hfe (อัตราขยายกระแส AC) จากจุดทำงานกระแสตรง (Q-point)
  • เพื่อคำนวณและวัดค่าพารามิเตอร์วงจรขยายสัญญาณกระแสสลับ: อัตราขยายแรงดัน (Av), ความต้านทานอินพุต (Zi), และความต้านทานเอาต์พุต (Zo)
  • เพื่อเปรียบเทียบความสัมพันธ์ระหว่างแบบจำลอง re Model และแบบจำลอง h-Parameter Model

⚡ สมการไฮบริดพารามิเตอร์ (Two-Port Model)

ในโครงสร้าง Common-Emitter แบบจำลองสองพอร์ต (Two-Port Network) ของทรานซิสเตอร์อธิบายด้วยสมการไฮบริด 2 สมการ:

vbe = hie • ib + hre • vce
ic = hfe • ib + hoe • vce

เนื่องจาก hre มีค่าน้อยมาก (~10-4) และ 1/hoe มีค่าสูงมาก (~40kΩ ขึ้นไป) ในทางปฏิบัติจึงนิยมใช้ แบบจำลองประมาณการ (Approximate h-Model)

🔄 การแปลงระหว่าง re Model และ h-Parameters

ความสัมพันธ์ระหว่างพารามิเตอร์ของแบบจำลอง re และแบบจำลอง h-Parameter เป็นดังนี้:

hie = β • re = hfe • (26 mV / IE)
hfe = β = ic / ib
hoe ≈ 1 / ro
hre ≈ 0

ช่วยให้สามารถคำนวณวงจรขยายด้วยข้อมูลที่ระบุใน Datasheet ของผู้ผลิตได้อย่างแม่นยำ

📊 สรุปสูตรการคำนวณวงจรขยายด้วย Approximate h-Model

พารามิเตอร์วงจร สูตรคำนวณจาก h-Parameter Model ความหมายทางวิศวกรรม
ความต้านทานอินพุตของทรานซิสเตอร์ (Zb) Zb = hie ความต้านทานไดนามิกมองเข้าที่ขา Base เมื่อต่อ CE Bypass
ความต้านทานอินพุตทั้งหมด (Zi) Zi = R1 || R2 || hie ความต้านทานรวมที่แหล่งจ่ายสัญญาณภายนอกมองเห็น
ความต้านทานเอาต์พุต (Zo) Zo = RC || (1 / hoe) ≈ RC ความต้านทานภายในฝั่งเอาต์พุตเมื่อมองย้อนกลับเข้าวงจร
อัตราขยายแรงดัน (Av) Av = - (hfe • RC) / hie อัตราการขยายขนาดแรงดันสัญญาณ AC (กลับเฟส 180°)
อัตราขยายกระแส (Ai) Ai ≈ hfe • [RB / (RB + hie)] อัตราขยายกระแสจากอินพุตสู่เอาต์พุต

👤 ข้อมูลผู้ทำปฏิบัติการ

1️⃣ ตอนที่ 1: การกำหนดจุดทำงาน DC และการหาค่า h-Parameters (hie & hfe)

บันทึกค่าแรงดันไฟตรงที่จุดทำงาน และสกัดค่าพารามิเตอร์ไฮบริด: hfe = β และ hie = β • re = hfe • (26mV / IE)

แรงดัน VB (V) แรงดัน VE (V) แรงดัน VC (V) กระแส IE (mA) อัตราขยายกระแส hfe ความต้านทานอินพุต hie (kΩ)

2️⃣ ตอนที่ 2: การวิเคราะห์และวัดค่าสัญญาณ AC ด้วยแบบจำลอง h-Model

คำนวณและวัดค่าอัตราขยายแรงดัน Av = (hfe • RC) / hie, ความต้านทานอินพุต Zi = R1 || R2 || hie, และความต้านทานเอาต์พุต Zo

แรงดัน Vi (mVp-p) แรงดัน Vo (Vp-p) อัตราขยายแรงดัน Av = vo / vi ความต้านทาน Zi (kΩ) ความต้านทาน Zo (kΩ) เฟสสัญญาณ (°)

2. พารามิเตอร์ hfe ของทรานซิสเตอร์ BJT มีความหมายเทียบเท่ากับค่าใดในวงจร?
3. พารามิเตอร์ hoe มีหน่วยเป็นอะไร และมีความสัมพันธ์กับความต้านทานเอาต์พุต ro อย่างไร?

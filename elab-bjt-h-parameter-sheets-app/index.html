การวิเคราะห์วงจรขยายสัญญาณด้วยแบบจำลอง h-Parameter ของ BJT

BJT AC Small-Signal Analysis using Hybrid (h-Parameter) Two-Port Model

🟣 สถานะ: ออนไลน์พร้อมจำลอง

📌 วัตถุประสงค์การทดลอง

  • เพื่อศึกษาและทำความเข้าใจโครงสร้าง แบบจำลองไฮบริดพารามิเตอร์ (Hybrid h-Parameter Model) ของทรานซิสเตอร์ BJT โครงสร้าง Common-Emitter (CE)
  • เพื่อสกัดหาค่าพารามิเตอร์ hie (ความต้านทานอินพุต) และ hfe (อัตราขยายกระแส AC) จากจุดทำงานกระแสตรง (Q-point)
  • เพื่อคำนวณและวัดค่าพารามิเตอร์วงจรขยายสัญญาณกระแสสลับ: อัตราขยายแรงดัน (Av), ความต้านทานอินพุต (Zi), และความต้านทานเอาต์พุต (Zo)
  • เพื่อเปรียบเทียบความสัมพันธ์ระหว่างแบบจำลอง re Model และแบบจำลอง h-Parameter Model

⚡ สมการไฮบริดพารามิเตอร์ (Two-Port Network Equations)

ในโครงสร้าง Common-Emitter (CE) แบบจำลองสองพอร์ต (Two-Port Network) ของทรานซิสเตอร์อธิบายด้วยสมการไฮบริด 2 สมการ:

vbe = hie • ib + hre • vce
ic = hfe • ib + hoe • vce

รูปแบบสมการเมทริกซ์ไฮบริด (Hybrid Matrix Formulation):

[ vbe ] = [ hie hre ] [ ib ]
[ ic ] [ hfe hoe ] [ vce ]

🔄 การแปลงระหว่าง re Model และ h-Parameters

ความสัมพันธ์ระหว่างพารามิเตอร์ของแบบจำลอง re และแบบจำลอง h-Parameter เป็นดังนี้:

hie = β • re = hfe • (26 mV / IE)
hfe = β = ic / ib
hoe ≈ 1 / ro
hre ≈ 0 (ในแบบจำลองโดยประมาณ)

ช่วยให้สามารถคำนวณวงจรขยายด้วยข้อมูลที่ระบุใน Datasheet ของผู้ผลิตได้อย่างสะดวกและแม่นยำ

📐 โครงสร้างแบบจำลองไฮบริดทูพอร์ต (Complete Hybrid Two-Port Model)

hie (Input Impedance) ความต้านทานอินพุต (โอห์ม) ขณะลัดวงจรเอาต์พุต (vce=0) ≈ βre
hre (Reverse Voltage Ratio) อัตราส่วนป้อนกลับแรงดันย้อนกลับ ขณะเปิดวงจรอินพุต (ib=0) ≈ 10-4
hfe (Forward Current Gain) อัตราขยายกระแสไปข้างหน้า (เท่า) ขณะลัดวงจรเอาต์พุต (vce=0) ≈ β
hoe (Output Admittance) ความนำเอาต์พุต (ซีเมนส์/ไมโครซีเมนส์) ขณะเปิดวงจรอินพุต (ib=0) ≈ 1/ro

📊 สรุปสูตรการคำนวณวงจรขยายด้วย Approximate h-Model (เปรียบเทียบสภาวะต่อ/ถอด CE)

พารามิเตอร์วงจร 🟢 กรณีต่อ CE (Bypassed: มี CE) 🔴 กรณีถอด CE (Unbypassed: ไม่มี CE) ความหมายทางวิศวกรรม / ข้อสังเกต
ความต้านทานอินพุตของ BJT (Zb) Zb = hie Zb = hie + (1 + hfe)RE
≈ hfe • RE		 ความต้านทานมองเข้าที่ขา Base (เมื่อถอด CE ค่า Zb จะเพิ่มขึ้นมหาศาลจากผลของ RE)
ความต้านทานอินพุตทั้งหมด (Zi) Zi = R1 || R2 || hie Zi = R1 || R2 || Zb ความต้านทานรวมที่แหล่งจ่ายสัญญาณภายนอกมองเห็น (RB || Zb)
ความต้านทานเอาต์พุต (Zo) Zo = RC || (1 / hoe) ≈ RC Zo = RC || (1 / hoe) ≈ RC ความต้านทานภายในฝั่งเอาต์พุตเมื่อมองย้อนกลับเข้าวงจร (ถูกจำกัดโดยตัวต้านทานโหลด RC)
อัตราขยายแรงดัน (Av) Av = - [hfe • (RC || 1/hoe)] / hie
≈ - (hfe • RC) / hie (เกนสูง) 		Av = - [hfe • (RC || 1/hoe)] / Zb
≈ - RC / RE (เกนต่ำ เสถียรสูง) 		อัตราการขยายแรงดันสัญญาณ AC (กลับเฟส 180°) มี CE ให้เกนสูงมาก ไม่มี CE ให้เกนคงที่เสถียรตามอัตราส่วน RC/RE
อัตราขยายกระแส (Ai) Ai ≈ hfe • [RB / (RB + hie)] Ai ≈ hfe • [RB / (RB + Zb)] อัตราส่วนกระแสเอาต์พุตต่อกระแสอินพุตจากแหล่งกำเนิด

⚙️ ระบบกำหนดค่าพารามิเตอร์วงจรสำหรับการทดลอง (h-Model)

เลือกรูปแบบการทำแล็บ: ใช้ชุดค่ามาตรฐานของใบงาน หรือป้อนกำหนดค่าพารามิเตอร์เองแบบ Dynamic

🎛️ แผงปรับแต่งค่าพารามิเตอร์วงจร BJT (Circuit Parameters)
เลือกเบอร์ทรานซิสเตอร์อ้างอิง:

1️⃣ ตอนที่ 1: การกำหนดจุดทำงาน DC และการหาค่า h-Parameters (hie & hfe)

บันทึกค่าแรงดันไฟตรงที่จุดทำงาน (VCC = 12 V, R1 = 33 kΩ, R2 = 6.8 kΩ, RC = 2.2 kΩ, RE = 560 Ω) และสกัดค่าพารามิเตอร์ไฮบริด: hfe = β และ hie = β • re = hfe • (26mV / IE)

แรงดัน VB (V) แรงดัน VE (V) แรงดัน VC (V) กระแส IE (mA) อัตราขยายกระแส hfe ความต้านทานอินพุต hie (kΩ)

2️⃣ ตอนที่ 2: การวิเคราะห์และวัดค่าสัญญาณ AC ด้วยแบบจำลอง h-Model

คำนวณและวัดค่าอัตราขยายแรงดัน Av = (hfe • RC) / hie, ความต้านทานอินพุต Zi = R1 || R2 || hie, และความต้านทานเอาต์พุต Zo (RC = 2.2 kΩ, RE = 560 Ω, hfe = 200)

แรงดัน Vi (mVp-p) แรงดัน Vo (Vp-p) อัตราขยายแรงดัน Av = vo / vi ความต้านทาน Zi (kΩ) ความต้านทาน Zo (kΩ) เฟสสัญญาณ (°)

2. พารามิเตอร์ hfe ของทรานซิสเตอร์ BJT มีความหมายเทียบเท่ากับค่าใดในวงจร?
3. พารามิเตอร์ hoe มีหน่วยเป็นอะไร และมีความสัมพันธ์กับความต้านทานเอาต์พุต ro อย่างไร?

Lab 14: Class AB Power Amp V1.0

วงจรขยายกำลังและวงจรกันชน (Power Amplifier & Emitter Follower)

Complementary Push-Pull Class AB · Speaker Load 4Ω/8Ω · Heatsink Thermal Simulation

🟢 สถานะ: ออนไลน์พร้อมจำลอง

🎯 วัตถุประสงค์การทดลอง

  • ศึกษาคุณสมบัติของวงจรขยายกระแสแบบ Common-Collector (Emitter Follower Buffer)
  • ศึกษาและคำนวณ อัตราขยายแรงดัน (Av ≈ 1), อัตราขยายกระแส (Ai ≫ 1), และ อัตราขยายกำลังงาน (Ap)
  • ศึกษาการคำนวณ กระแสเอาต์พุตพีค (Ip), กระแส RMS (Irms), และ กระแสแหล่งจ่ายไฟ DC (IDC)
  • ศึกษาการทำงานของวงจรขยายกำลังคู่เสริมสมมาตร (Complementary Symmetry Class AB Push-Pull)
  • วิเคราะห์ผลกระทบของอิมพีแดนซ์โหลดลำโพง 4 Ω และ 8 Ω ต่อกำลังขับ (Pout), กำลังสูญเสีย (PD), และกระแสเอาต์พุต
  • ศึกษาและสังเกตความเพี้ยนรอยต่อ (Crossover Distortion) ใน Class B และการขจัดความเพี้ยนด้วย Class AB Diode Bias
  • ทำความเข้าใจความสำคัญของ แผ่นระบายความร้อน (Heatsink) และการป้องกันสภาวะ Thermal Runaway

🎛️ 1. อัตราขยายและอิมพีแดนซ์ (Gain & Impedance)

อัตราขยายแรงดัน (Voltage Gain Av):
Av = Vout / Vin = RL / (RL + re + RE) ≈ 0.98 ≈ 1 (In-Phase 0°)

อัตราขยายกระแส (Current Gain Ai):
Ai = Iout / Iin ≈ β + 1 ≫ 1 (ขยายกระแสหลายสิบถึงร้อยเท่า)

อัตราขยายกำลังงาน (Power Gain Ap):
Ap = Pout / Pin = Av × Ai ≈ Ai (ขยายกำลังขับเสียงสูงสุด)

อิมพีแดนซ์อินพุตและเอาต์พุต (Zin & Zout):
Zin = R1 ‖ R2 ‖ [(β + 1)(re + RE + RL)] (สูงมาก ไม่โหลดภาคหน้า)
Zout = RE + re + [RS / (β + 1)] ≈ < 0.5 Ω (ต่ำมาก ขับลำโพงได้เต็มที่)

⚡ 2. การคำนวณกระแสไฟฟ้าและกำลังงาน (Current & Power)

กระแสเอาต์พุตพีค (Peak Output Current Ip):
Ip(out) = Vp(out) / RL = (Vin(p-p) / 2) / RL

กระแสยังผล (RMS Output Current Irms):
Irms = Ip / √2 = 0.707 × Ip

กำลังขับเอาต์พุตเสียง (Output Power Pout):
Pout = Vp2 / (2RL) = Irms2 × RL = Vrms2 / RL

กระแสและกำลังงานจากแหล่งจ่าย (DC Supply IDC & PDC):
IDC(avg) = (2 × Ip) / π = (2 × Vp) / (π × RL)
PDC = 2VCC × IDC(avg) = (2VCC × Vp) / (π × RL)

ประสิทธิภาพของวงจร (Efficiency η):
η = (Pout / PDC) × 100% = (π/4) × (Vp / VCC) ≈ 78.5% (Max)

📐 3. แบบจำลองและพารามิเตอร์ AC ของทรานซิสเตอร์ (re Model Parameters)

ความต้านทานรอยต่ออีมิเตอร์ AC (Dynamic Emitter Resistance re):
re = VT / IE = 26 mV / IE(mA) (ที่ 25°C-28°C, VT ≈ 26mV)
• เมื่อกระแสโหลดสูง (IE = 1A) → re = 26mV / 1000mA = 0.026 Ω (ต่ำมาก)
• เมื่อกระแสสงบ (IQ = 25mA) → re = 26mV / 25mA = 1.04 Ω

พารามิเตอร์ของแบบจำลองสัญญาณขนาดเล็ก (Small-Signal Parameters):
• อัตราขยายกระแส AC (β หรือ hfe): β = ic / ib (TIP31C β≈50, 2N3055 β≈35)
• ความต้านทานอินพุตขาเบส (rπ หรือ hie): rπ = β × re
• อิมพีแดนซ์มองเข้าเบสรวมโหลด (Zb): Zb = β(re + RE + RL)
• ความนำข้ามสัญญาณ (Transconductance gm): gm = IC / VT = 1 / re = β / rπ
• แหล่งจ่ายกระแสควบคุม: ic = β·ib = gm·vbe และ ie = (β + 1)ib
• ความต้านทานพลวัตไดโอดไบแอส (rd): rd = 26mV / ID ≈ 1 - 2 Ω (ลัดวงจรทาง AC)

🌡️ 4. กำลังสูญเสียความร้อนและแผ่นระบายความร้อน (Heatsink)

กำลังสูญเสียความร้อนรวม (Power Dissipation PD):
PD(total) = PDC − Pout (กระจายใน Q1 และ Q2 คนละครึ่ง: PD(Q) = PD / 2)

อุณหภูมิรอยต่อทรานซิสเตอร์ (Tj Junction Temp):
Tj = TA + PD(Q) × (θjc + θcs + θsa)
• θjc = ความต้านทานความร้อนรอยต่อถึงตัวถัง (Junction to Case, ~1.5 - 3.1 °C/W)
• θcs = ความต้านทานความร้อนซิลิโคนระบายความร้อน (Case to Heatsink, ~0.5 °C/W)
• θsa = ความต้านทานความร้อนแผ่นระบายความร้อน (Heatsink to Ambient, ~4.5 °C/W)
⚠️ กรณีไม่มี Heatsink (θja ≈ 62.5 °C/W) → Tj > 150°C ทรานซิสเตอร์จะไหม้ทะลุ (Thermal Runaway) ทันที!

🌊 5. ความเพี้ยนรอยต่อ (Crossover Distortion) ใน Class B vs Class AB

สาเหตุการเกิด Crossover Notch ใน Class B:
ทรานซิสเตอร์ซิลิคอนต้องการแรงดัน VBE ≥ 0.65V ถึงจะเริ่มนำกระแส เมื่อสัญญาณเสียงตัดผ่านจุด 0V (Zero-Crossing) ในช่วง -0.65V ถึง +0.65V จะไม่มีทรานซิสเตอร์ตัวใดทำงาน ทำให้รูปคลื่นเกิด Deadband Notch (รอยบากแบน) เสียงจะเพี้ยนแหบ

การแก้ปัญหาด้วย Class AB Diode Biasing:
ต่อไดโอด D1, D2 อนุกรมคั่นระหว่างขาเบส Q1 และ Q2 เพื่อสร้างแรงดันตกคร่อมชดเชย 2 × VD ≈ 1.4V ดึงขาเบสทั้งสองให้อยู่ที่ขอบเขตพร้อมนำกระแสพอดี (Quiescent Bias) ทำให้รูปคลื่นเสียงเชื่อมต่อกันได้อย่างต่อเนื่องและเรียบเนียนไร้รอยต่อ

📋 ตารางเปรียบเทียบ: ลำโพง 4Ω vs 8Ω และบทบาทของ Buffer & Heatsink

พารามิเตอร์ โหลดลำโพง 4 Ω โหลดลำโพง 8 Ω ผลของการมีแผ่นระบายความร้อน (Heatsink)
กำลังขับ Pout สูงกว่า (~2 เท่า) ให้เสียงดังกว่า ต่ำกว่า (~ครึ่งหนึ่ง) รักษากำลังขับต่อเนื่องได้โดยไม่เกิด Thermal Limiting
กระแสสูงสุด Ip Ip = Vp / 4Ω (ดึงกระแสสูง 2 เท่า) Ip = Vp / 8Ω (ดึงกระแสน้อยกว่า) ทรานซิสเตอร์ต้องรองรับพิกัด IC(max)
ความร้อนสะสม PD สูงมาก ทรานซิสเตอร์ร้อนเร็ว ปานกลาง ทรานซิสเตอร์ทำงานเบาแรง ถ่ายเทความร้อนสู่อากาศ ป้องกัน Thermal Runaway
Damping Factor ต่ำกว่า การควบคุมกรวยลำโพงปานกลาง สูงกว่า เบสกระชับ คมชัด ความเพี้ยนต่ำ ช่วยรักษาเสถียรภาพจุดทำงาน Q-point

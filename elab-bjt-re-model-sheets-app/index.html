BJT AC Small-Signal Analysis using re Transistor Equivalent Circuit

🟢 สถานะ: ออนไลน์พร้อมจำลอง

📌 วัตถุประสงค์การทดลอง

  • เพื่อศึกษาและเข้าใจโครงสร้าง แบบจำลองความต้านทานไดนามิก re (AC Small-Signal re Model) ของทรานซิสเตอร์ BJT
  • เพื่อคำนวณและวัดหาค่า re = 26 mV / IE จากจุดทำงานกระแสตรง (Q-point)
  • เพื่อวิเคราะห์และเปรียบเทียบพารามิเตอร์สัญญาณกระแสสลับ (Av, Zi, Zo) ระหว่างวงจรที่มีและไม่มีตัวเก็บประจุบายพาส (CE)
  • เพื่อสังเกตการกลับเฟส 180° ระหว่างสัญญาณอินพุต (vi) และเอาต์พุต (vo) ในวงจรขยายแบบ Common-Emitter

⚡ ทฤษฎีค่าความต้านทานไดนามิก re

ในสภาวะสัญญาณกระแสสลับขนาดเล็ก รอยต่อ Base-Emitter มีคุณสมบัติเสมือนไดโอดไบแอสตรง ค่าความต้านทานไดนามิกของอิมิตเตอร์ re ถูกกำหนดโดยกระแสไฟตรง IE:

re = VT / IE ≈ 26 mV / IE (mA) [ที่อุณหภูมิห้อง 300K]

เมื่อ IE เพิ่มขึ้น ค่า re จะลดลง ส่งผลให้อัตราขยายสัญญาณกระแสสลับของวงจรเปลี่ยนแปลงตามไปด้วย

🔄 การเปรียบเทียบผลของ Bypass Capacitor (CE)

ในวงจร Common Emitter การต่อตัวเก็บประจุ CE ขนานคร่อม RE จะทำหน้าที่เป็น Short Circuit สำหรับสัญญาณ AC:

[มี CE (Bypassed)]: Av = - RC / re (อัตราขยายสูงมาก)
[ไม่มี CE (Unbypassed)]: Av ≈ - RC / (re + RE) ≈ - RC / RE

การไม่มี CE จะทำให้อัตราขยายลดลง แต่จะได้เสถียรภาพสูงและความต้านทานอินพุต Zi ที่เพิ่มขึ้นอย่างมาก

📊 สรุปสูตรการคำนวณวงจรสมมูล re Model

พารามิเตอร์ กรณีมีตัวเก็บประจุบายพาส (CE Bypassed) กรณีไม่มีตัวเก็บประจุบายพาส (Unbypassed RE)
ความต้านทานขาเบส (Zb) Zb = β • re Zb ≈ β (re + RE)
ความต้านทานอินพุต (Zi) Zi = R1 || R2 || βre Zi = R1 || R2 || [β(re + RE)]
ความต้านทานเอาต์พุต (Zo) Zo ≈ RC Zo ≈ RC
อัตราขยายแรงดัน (Av) Av = - RC / re Av = - RC / (re + RE) ≈ - RC / RE
ความต่างเฟส (θ) 180° (กลับเฟส Inverted) 180° (กลับเฟส Inverted)

ใบงานการทดลองที่ 16: วงจรขยายแบบป้อนกลับลบ (Negative Feedback Amplifiers)

Closed-Loop Gain Stability, Bandwidth Extension & Distortion Reduction
กลับสู่ E-Lab Portal

วัตถุประสงค์การทดลอง (Objectives)

  • เพื่อศึกษาแนวคิดและหลักการทำงานของการป้อนกลับแบบลบ (Negative Feedback) ในวงจรขยายอิเล็กทรอนิกส์
  • เพื่อคำนวณและพิสูจน์สมการอัตราขยายวงปิด \(A_f = \frac{A}{1 + A\beta}\) และสัดส่วนป้อนกลับ \(\beta = \frac{R_1}{R_1 + R_f}\)
  • เพื่อสังเกตการรักษาเสถียรภาพของอัตราขยาย (Gain Desensitivity) ไม่ให้แปรปรวนตามการเปลี่ยนแปลงของอัตราขยายวงเปิด \(A\)
  • เพื่อศึกษาการขยายแถบความถี่ตอบสนอง (Bandwidth Extension) ตามสมการ \(BW_f = BW \times (1 + A\beta)\)
  • เพื่อวิเคราะห์การลดทอนความเพี้ยนไม่เชิงเส้น (Harmonic Distortion Reduction) และการปรับปรุงอิมพีแดนซ์อินพุต/เอาต์พุต

1. นิยามและสมการหลักการป้อนกลับลบ

การป้อนกลับลบทำได้โดยการนำสัญญาณเอาต์พุตบางส่วน (\(V_f = \beta V_o\)) ย้อนกลับมาหักล้าง (ลบ) กับสัญญาณอินพุต ทำให้สัญญาณผลต่างที่ส่งเข้าวงจรขยายมีค่าลดลง (\(V_d = V_i - V_f\))

อัตราขยายวงปิด (Closed-Loop Gain):
\[A_f = \frac{A}{1 + A\beta}\]
เมื่อ \(A\beta \gg 1\) (Loop Gain สูงมาก):
\[A_f \approx \frac{1}{\beta} = \frac{R_1 + R_f}{R_1} = 1 + \frac{R_f}{R_1}\]
ตัวคูณเสถียรภาพ (Desensitivity Factor):
\[D = 1 + A\beta\]

💡 ความเสถียรของเกน: ความผันผวนของอัตราขยายจะลดลงเหลือเพียง \(\frac{dA_f}{A_f} = \frac{1}{1 + A\beta} \left(\frac{dA}{A}\right)\)

2. การขยายแบนด์วิดท์และการลดความเพี้ยน

การยอมลดอัตราขยายลงด้วยตัวหาร \((1 + A\beta)\) จะได้รับประโยชน์ตอบแทนโดยตรงคือ แบนด์วิดท์ขยายกว้างขึ้นในสัดส่วนเดียวกัน และความเพี้ยนฮาร์มอนิกลดลงอย่างมีนัยสำคัญ

แบนด์วิดท์วงปิด (Closed-Loop Bandwidth):
\[BW_f = BW \times (1 + A\beta)\]
ผลคูณอัตราขยาย-แบนด์วิดท์ (GBW Product):
\[A \times BW = A_f \times BW_f = \text{Constant}\]
การลดความเพี้ยนฮาร์มอนิก (Distortion):
\[D_f = \frac{D}{1 + A\beta}\]

💡 ข้อสังเกต: รูปคลื่นเอาต์พุตที่มีการคลิปหรือเพี้ยนในโหมดเปิดลูป จะกลับมาเรียบเนียนเป็นคลื่นไซน์บริสุทธิ์เมื่อปิดลูปป้อนกลับ

ข้อที่ 2: สมการความสัมพันธ์ของอัตราขยายวงปิด (\(A_f\)) กับอัตราขยายวงเปิด (\(A\)) และสัดส่วนป้อนกลับ (\(\beta\)) คือข้อใด?

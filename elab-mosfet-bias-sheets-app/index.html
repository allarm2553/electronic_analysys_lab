JFET & MOSFET Fixed-Bias Lab

ใบงานการทดลองที่ 6: การจัดไบอัสคงที่ของ JFET และ MOSFET (Fixed-Bias Configuration)

วิชา: วิเคราะห์วงจรอิเล็กทรอนิกส์ (Electronic Circuit Analysis)

1. วัตถุประสงค์เชิงปฏิบัติการ

  • เพื่อศึกษาโครงสร้างและการทำงานของวงจรจัดไบอัสคงที่ (Fixed-Bias Configuration) สำหรับทรานซิสเตอร์สนามไฟฟ้า JFET และ MOSFET
  • เพื่อศึกษาพฤติกรรมกระแสเกตเป็นศูนย์ (IG ≈ 0 A) และคุณสมบัติการควบคุมกระแสด้วยแรงดัน (Voltage-Controlled Device)
  • เพื่อทดลองพล็อตเส้นคุณลักษณะการถ่ายโอน (Transfer Characteristics: ID vs VGS) และคุณลักษณะเดรน (Drain Characteristics: ID vs VDS)
  • เพื่อสกัดหาค่าพารามิเตอร์ขีดเริ่มทางฟิสิกส์ (Pinch-off Voltage: VP, IDSS สำหรับ JFET และ Threshold Voltage: Vth, k สำหรับ MOSFET)

2. ทฤษฎีวงจร Fixed-Bias และสมการทางไฟฟ้า

วงจรไบอัสคงที่ (Fixed-Bias Circuit) เป็นวงจรพื้นฐานที่จ่ายแรงดันกระแสตรงคงที่ VGG ผ่านตัวต้านทานเกต RG (ขนาดใหญ่ เช่น 1 MΩ) เข้าที่ขาเกต (Gate) และมีตัวต้านทานโหลดเดรน RD ต่ออนุกรมกับขาเดรน (Drain) เข้ากับแหล่งจ่ายหลัก VDD โดยที่ขาซอร์ส (Source) ต่อลงกราวด์โดยตรง (VS = 0 V)

2.1 ลูปอินพุตและแรงดันเกต-ซอร์ส (Gate-Source Voltage: VGS)

เนื่องจากชั้นรอยต่อเกตของ JFET ได้รับไบอัสย้อนกลับ และเกตของ MOSFET มีชั้นฉนวนออกไซด์กั้น ส่งผลให้กระแสเกตมีค่าน้อยมากจนเป็นศูนย์:

IG ≈ 0 A  ⇒  VRG = IG × RG = 0 V  ⇒  VGS = VGG

2.2 ลูปเอาต์พุตและสมการเดรน (Drain Characteristics)

จากกฎแรงดันของเคอร์ชอฟฟ์ (KVL) ในลูปเดรน-ซอร์ส:

VDS = VDD - ID RD

JFET (สมการช็อกเลย์ / Shockley's Equation)

สำหรับ JFET N-Channel ไบอัสย้อนกลับ (VP ≤ VGS ≤ 0 V) ในย่านอิ่มตัว (Saturation):

ID = IDSS (1 - VGS / VP)2

เมื่อ VGS ≤ VP อุปกรณ์จะเข้าสู่ย่านคัทออฟ (ID = 0 A)

E-MOSFET (สมการกำลังสอง / Square-Law)

สำหรับ E-MOSFET N-Channel เมื่อได้รับไบอัสบวก (VGS > Vth) ในย่านอิ่มตัว (Saturation):

ID = k (VGS - Vth)2

เมื่อ VGS ≤ Vth อุปกรณ์จะเข้าสู่ย่านคัทออฟ (ID = 0 A)

ตอนที่ 1: ตารางบันทึกคุณลักษณะการถ่ายโอน (Transfer Characteristics: ID vs VGS เมื่อ VDS ≈ 10 V)

ปรับระดับแรงดันแหล่งจ่ายเกต VGG ตามค่าที่กำหนดในตาราง สังเกตและบันทึกระดับแรงดันตกคร่อม VDS และกระแสเดรน ID:
แรงดันไบอัสเกต VGS (V) แรงดันวัดจริง VDS (V) กระแสไฟฟ้าเดรน ID (mA) สถานะการนำกระแส ดึงค่าวัด

ตอนที่ 2: ตารางบันทึกคุณลักษณะเดรน (Drain Characteristics: ID vs VDS เมื่อ VGS คงที่)

ล็อกแรงดันป้อนเกต VGS คงที่ตามจุดทำงาน แล้วปรับระดับแหล่งจ่าย VDD ตามตาราง วัดกระแสเดรนและแรงดันตกคร่อมขั้วเดรน-ซอร์ส:

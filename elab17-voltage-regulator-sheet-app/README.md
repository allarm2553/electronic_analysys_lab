# ใบงานการทดลองที่ 17: วงจรรักษาระดับแรงดันด้วยไอซีเร็กกูเลเตอร์ 78xx และ 79xx
**E-Lab 17: IC Voltage Regulators (78xx Positive & 79xx Negative Series)**

## 1. วัตถุประสงค์ (Objectives)
1. เพื่อศึกษาโครงสร้าง การจัดขา (Pinout TO-220) และคุณสมบัติของไอซีเร็กกูเลเตอร์แรงดันบวก 78xx และแรงดันลบ 79xx
2. เพื่อทดสอบและวิเคราะห์คุณสมบัติการรักษาระดับแรงดันเทียบกับแรงดันอินพุต (Line Regulation) และแรงดัน Dropout ($V_{dropout} \approx 2.0\text{V}$)
3. เพื่อทดสอบและวิเคราะห์คุณสมบัติการรักษาระดับแรงดันเทียบกับกระแสโหลด (Load Regulation) และกำลังงานสูญเสีย ($P_D$) ตลอดจนการระบายความร้อน
4. เพื่อศึกษาการต่อวงจรแหล่งจ่ายไฟคู่สมมาตร $\pm 12\text{V}$ / $\pm 15\text{V}$ (Dual-Polarity Power Supply) ร่วมกับหม้อแปลง Center-Tapped

---

## 2. โครงสร้างไฟล์ประจำแล็บ (File Architecture)
- `index.html`: เว็บแอปพลิเคชันห้องปฏิบัติการเสมือนจริง 4 แท็บ (ทฤษฎี, ห้องทดลองจำลอง, ตารางบันทึกผล, คำถามและสรุปผล) พร้อมเครื่องมือวัดออสซิลโลสโคปคู่และระบบตรวจคะแนน 10 คะแนนเต็ม
- `Code.gs` / `Code.js`: สคริปต์หลังบ้าน Google Apps Script สำหรับรับส่งข้อมูล และบันทึกลง Google Sheets
- `appsscript.json`: Manifest config สำหรับ Google Apps Script V8 runtime

---

## 3. เกณฑ์การให้คะแนน (10.0 คะแนนเต็ม)
- **ตอนที่ 1 (3.0 คะแนน)**: การทดสอบ Line Regulation และแรงดัน Dropout ($V_{in}$ Sweep 7 จุด)
- **ตอนที่ 2 (3.0 คะแนน)**: การทดสอบ Load Regulation (6 สภาวะโหลด) กำลังสูญเสีย $P_D$ และการจัดขา TO-220
- **ตอนที่ 3 (4.0 คะแนน)**: คำถามวัดความเข้าใจปรนัย 4 ข้อ (ข้อละ 1.0 คะแนน)
